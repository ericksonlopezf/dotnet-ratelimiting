# Support Guidelines

Thank you for using `EricksonLopez.RateLimiting`! We provide multiple channels for technical assistance, bug reporting, and architectural guidance.

---

## Channels of Support

### 1. Documentation & Architecture Reference
Before opening an issue, check the official documentation hub and architectural guides:
- [Repository README](./README.md) — Public API Reference, Quick Start, and Feature Overview
- [Architecture Justification](./docs/architectural-justification.md) — System Invariants and Boundary Ownership
- [Architectural Decision Records (ADRs)](./docs/adr/) — ADR-001 through ADR-009
- [CI/CD & Quality Pipeline Guide](./docs/ci-cd-pipeline.md) — Build, Workflows, and Quality Gates
- [NuGet Packages Reference](./docs/nuget-packages.md) — Package Matrix and Public API Contract

### 2. Bug Reports & Issues
If you encounter a bug or unexpected behavior:
1. Search existing [GitHub Issues](https://github.com/ericksonlopezf/dotnet-ratelimiting/issues) to check if the issue has already been reported.
2. If not, open a new issue using our structured [Bug Report Template](https://github.com/ericksonlopezf/dotnet-ratelimiting/issues/new?template=bug-report.md).
3. Include the .NET runtime version (`net8.0`, `net9.0`, `net10.0`), package version (`1.0.0`), and a minimal reproducible example.

### 3. General Questions & Feature Proposals
For architectural design questions, configuration assistance, or feature proposals:
- Participate in [GitHub Discussions](https://github.com/ericksonlopezf/dotnet-ratelimiting/discussions).
- Or submit a feature proposal using our [Feature Request Template](https://github.com/ericksonlopezf/dotnet-ratelimiting/issues/new?template=feature-request.md).

### 4. Security Inquiries
For sensitive security reports:
- Refer to [SECURITY.md](./SECURITY.md) and report privately to **[ericksonlopezf@gmail.com](mailto:ericksonlopezf@gmail.com)**.
- **DO NOT** post vulnerability details in public issues or discussions.

### 5. Direct Maintainer Correspondence
For enterprise integration or maintainer correspondence:
- Contact **Erickson Lopez** directly at: **[ericksonlopezf@gmail.com](mailto:ericksonlopezf@gmail.com)**.
